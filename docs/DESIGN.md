# 本机工作室

独立于办公室 0.8.0。应用 ID local.agentoffice.studio，用户配置 AgentOfficeStudio，任务数据 AgentOfficeStudio，桌面入口“本机工作室”。不接管、迁移或停止旧服务。

视觉：遵循使用者已选的 Codex 简洁导航和现代数字办公室。主色 #F5F6F7 / #FAFAFA / #202122 / #73787D / #4C6F65 / #5078AF，告警 #B77A32。使用系统中文字体，正文 14px，页面标题 28px。场景是主要视觉区域，其余界面保持清楚、紧凑。保留拖动、滚轮缩放、工位、老板办公室、休闲区和已有动作。

新增页面围绕成员、项目任命、任务依赖和成果验收；工位按成员分配，离线/未验证状态不表现为空闲。随机气泡与真实业务事件分开。通过文本、状态图标和颜色共同表达状态。

数据：本机 SQLite；项目/成员/任命/任务/执行/审批/成果/事件分别存储。计划须人工确认，执行依赖和复核推进由服务判断，未知执行先核对。默认暂停自动派发。

驱动：Codex App Server stdio；Hermes / DSH ACP stdio。仅管理工作室自己建立的会话。保留引擎原生权限，不将永久授权作为默认选择。成员工作提示词不等同权限沙箱。

隔离：角色提示词、工作说明、验收标准按本次执行快照保存；原生引擎的个人历史不自动导入。复核仅使用本项目的明确成果。
