本机工作室 0.1.1

这是新建的个人多 Agent 项目协作客户端。桌面名称为“本机工作室”，与“办公室 0.8.0”分开安装和保存数据。

首次使用
1. 打开“接入中心”，检测本机已经安装的 Codex、Hermes、DeepSeek Harness。
2. 选择或配置本机程序入口，检查连接并读取模型选项。
3. 添加成员，或生成一次性接入提示词，复制给自己的 Agent 执行。接入助手会注册成员并检查连接。
4. 建立项目，选择本机目录，写清目标和验收要求。
5. 在项目的“团队与任命”中指定项目经理、执行和复核成员。
6. 可以让项目经理“整理计划”，确认后创建任务；也可以手动建任务。
7. 自动派发默认暂停。准备好后开启，或手动执行一条任务。

引擎与模型
客户端自带 Node 和本机数据库组件。各引擎使用自己的安装、登录和工具配置。
“已连接”表示接口检查通过，实际模型登录和额度仍由引擎检查。
DSH 的账号模型和 API Key 模型是不同路由。已有 DSH 账号登录的使用者，可在成员的模型选项中选择 DeepSeek Account；API 路由需要在原引擎配置对应凭据。
Windows 的 DSH 桌面程序即使尚未注册 dsh 命令，也可以选择 DeepSeek Harness.exe，适配器会使用它自带的 CLI。
模型推理沿用引擎配置，使用云端模型时仍需联网；项目管理和调度在当前电脑上运行。

项目协作
计划由你确认。成员按批准的任务执行，成果交给不同成员复核。
复核通过后，满足依赖的后续任务可以派发；最终由你验收项目。
复核要求返工时按项目上限推进，超过上限或缺少证据时提交你处理。
一位成员可以参加多个项目；同一个引擎连接的工作排队执行。
同一物理项目目录内的写入与复核串行，减少变更冲突。需要并行开发时，可以先建立独立工作区并作为不同项目目录管理。
原生引擎仍负责工具和文件权限。岗位说明用于明确职责，不等于操作系统沙箱。

草稿与场景
想法可以先保存，不必马上选择引擎。转为任务时选择项目、执行成员、复核人及验收条件。
草稿箱的「删除」将想法移入废纸篓。废纸篓可以恢复或彻底删除草稿。
在任务看板拖动卡片时，可用的目标列会高亮并显示具体操作。草稿和待执行可以互相移动，拖入「正在执行」会启动执行或复核，拖入「已完成」会打开人工验收。拖动正在运行的卡片到「需要处理」会请求停止，任务状态随引擎确认更新。
在看板草稿卡片上可以「删除草稿」。如果其他任务把这条草稿列为前置，先调整依赖。如果草稿由想法转换而来，原想法会回到草稿箱。
在项目详情可「删除项目」。请先停止或核对该项目的执行。确认后删除该项目的工作室记录，项目目录和本机成果文件保留，关联想法保留在草稿箱。
办公室工位对应成员；任务大屏显示工作状态，老板电脑汇总需要你处理的事项。
支持默认拖动、鼠标滚轮缩放、分区聚焦、大场景专注模式、自定义工作室和老板名称。
人物随机活动和气泡属于场景表现，真实进展来自任务记录。

暂停、停止与后台
暂停自动派发只停止领取新工作，当前执行会继续。当前轮次可以在任务详情中停止。
关闭客户端窗口后，本机后台按现有设置继续工作。
更新新客户端前，请在设置中“结束本机后台”并关闭窗口；有执行或未知结果时会先要求核对。
电脑休眠和关机后需要重新核对执行。未知结果不会自动重复派发；确认旧执行结束后可手动重新安排。

数据与分享
Windows 数据：当前用户 LocalAppData/AgentOfficeStudio。
Mac 数据：~/Library/Application Support/AgentOfficeStudio。
窗口配置另存于当前用户 AgentOfficeStudio 配置目录。
新版管理自己创建或接续的专用工作会话，旧版项目、看板和个人聊天不自动迁移。
分享安装压缩包即可；源码包用于继续开发。分享包不包含本机数据库、登录凭据、个人连接配置或验收项目数据。

验证范围
Windows 本机三个引擎接口已握手；已跑通 Hermes 规划、Codex 执行、DSH 账号模型复核、项目验收的简短文字型真实流程。
复杂代码项目、不同引擎版本和操作系统组合需要按实际项目继续验收。
Mac 安装包属于交叉打包预览版，尚未完成 Mac 真机启动、签名公证和三引擎协作验收。
